## Simpleact

Простая копия React, реализующая базовый функционал.

[Демо](https://alexeyshirko.github.io/simpleact/)

### Что уже есть

- JSX через automatic runtime
- Теги, текст, фрагменты и функциональные компоненты
- Пропсы: DOM-свойства, атрибуты `data-*` и `aria-*`, `style` объектом
- Обновление DOM через сравнение детей по индексу
- `useState` с объединением обновлений в одной перерисовке

### Запуск

```bash
npm install
npm run demo
```
